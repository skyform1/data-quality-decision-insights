3. Description: Analytical application for dataset validation, data-quality findings and evidence-linked review actions.

5. Choose Upload files. Drag the extracted contents, not the ZIP or enclosing folder.
6. Include backend, frontend, docs, examples, sample_data, scripts, README.md and DEMO.html. Include .gitignore if visible.
